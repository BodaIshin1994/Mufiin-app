# Muffin · Заказ кофе

Внутреннее приложение для заказа кофе в офисном кафе **Muffin**: сотрудник оформляет заказ с телефона, бариста видит его в реальном времени и ведёт по статусам, сотруднику остаётся спуститься и оплатить на кассе.

## Возможности

- Меню с опциями: температура (горячий/холодный), размер, молоко, сахар, добавки
- Статусы заказа: Новый → Принят → Готовится → Готов → Забрали/Оплачен
- Мгновенная синхронизация сотрудник ↔ бариста через Firebase Firestore
- Устанавливается на телефон как приложение (PWA), без App Store
- Уведомление сотруднику, когда заказ готов

## Стек

Обычные HTML/CSS/JS + Firebase (Firestore, Authentication, Hosting) — без сборщиков и фреймворков.

## Как развернуть

Полная пошаговая инструкция — в [`DEPLOY.md`](./DEPLOY.md): создание проекта Firebase, конфиг, `firebase deploy`, установка на телефон как иконки на рабочем столе.

## Структура

- `index.html`, `app.js`, `styles.css` — само приложение
- `firebase-config.js` — сюда вставляются ключи вашего проекта Firebase
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA (иконка, офлайн-оболочка)
- `firebase.json`, `firestore.rules`, `firestore.indexes.json` — конфигурация Firebase Hosting/Firestore
